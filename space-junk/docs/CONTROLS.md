# Space Junk: Salvagers — Controls

## Desktop
| Input | Action |
|-------|--------|
| W / S | Thrust forward / reverse along **ship nose** |
| A / D | Strafe left / right |
| Mouse | Look — **pitch** and **yaw** (pointer lock on click) |
| Space | Boost |
| LMB | Fire |
| RMB / F | Magnet beam |
| Q | Scan pulse |
| Esc | Pause · U upgrades while paused |

## Touch
| Control | Action |
|---------|--------|
| **Left stick** | Move (thrust / strafe in ship space) |
| **Right stick** | Look / pitch |
| Magnet · Boost · Fire | Right button cluster (unchanged) |
| HUD Pulse | Scan |

Camera chase follows ship pitch. Pitch ladder + ALT read sit beside the radar.
