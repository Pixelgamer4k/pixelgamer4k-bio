# Signal Lost assets

All runtime art and audio in this opening slice are **original procedural** content:

- Tile/character sprites: generated at runtime via HTML Canvas (Pixel Gamer 4k original)
- Music & SFX: procedural Web Audio API synthesizer (original MIDI-style / chiptune)

No third-party sprite sheets, MIDI files, or YouTube-derived media are included.

When adding future CC0 / CC-BY packs, vendor them under `public/assets/` with their LICENSE and credit them here.
