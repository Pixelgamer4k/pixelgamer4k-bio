# Pixel Gamer 4k — Bio

Yellow brand bio site + **Space Junk: Salvagers** Zone 1 (Orbital Debris).

- Live bio: GitHub Pages from `main/`
- Play: `/play/` — Vite + Three.js client-only game (IndexedDB saves, no analytics)
- Source: `space-junk/` — `npm install && npm run build` outputs to `play/`

## Controls
- WASD move (stick up = camera-forward)
- Mouse aim · LMB Fire · RMB Magnet · Space Boost · Q / HUD Scan
- Mobile: stick left; Magnet · Boost · Fire right

## Privacy
Client-side only. No trackers.
