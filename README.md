# Pixel Gamer 4k — Bio

Static brand bio website for **Pixel Gamer 4k**, hosted on GitHub Pages.

- **Live Bio**: [pixelgamer4k.github.io/pixelgamer4k-bio](https://pixelgamer4k.github.io/pixelgamer4k-bio/)
- **Hosting**: GitHub Pages from `main` branch (pure static)

## Features

- **Brand Styling**: Bold yellow field (`#FEDD04`) with dark ink (`#202022`) and official PG 4K lockup.
- **Direct Open**: The page opens straight to the bio. No intro video, music, or animation.
- **Funding Progress**: WZM Offline Revival bar, set by `data-raised` / `data-goal` on the `#fund` section in `index.html`.
- **Download**: Button below the funding bar (`#downloadBtn` in `index.html`).
- **Updater**: Run `./update-site.sh` to change the amount raised and the download link. Press Enter to keep a value.
